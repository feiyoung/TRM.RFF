# TRM.RFF

`TRM.RFF` provides estimation and inference for nonlinear threshold regression models with multivariate regime boundaries. Nonlinear boundaries are approximated using random Fourier features (RFF). The package provides hard-regime regression refitting, HAC inference, regime classification, simulation tools, and a dependent-wild-bootstrap Sup-Wald test for regime effects.

The model is

$$
Y_t = X_t^\top \alpha_0 + (X_t^\top \beta_0)
\mathbf{1}\{f_0(Z_t) \ge U_t\} + \varepsilon_t.
$$

## Installation

```r
remotes::install("feiyoung/TRM.RFF")
library(TRM.RFF)
```

## Main functions

- `TRM.RFF()` fits the nonlinear threshold regression model.
- `generate_AR()` generates an example autoregressive threshold-regression data set.
- `supWald.RFF()` tests the null hypothesis of no regime effects using a dependent wild bootstrap.
- `coef()`, `vcov()`, `confint()`, and `summary()` summarize fitted models.

## Example

```r
library(TRM.RFF)

## Generate data
dat <- generate_AR(n = 500, seed = 123)

## Fit the model
fit <- TRM.RFF(
  Y = dat$Y, X = dat$X,
  Z = dat$Z, U = dat$U,
  rff_dim = 15,
  h = 0.025,
  sigma_h = 1
)

## Results
vcov(fit)
summary(fit)
coef(fit)
confint(fit)

## Regime recovery
mean(fit$D != dat$D0)
str(fit)
fit

## Sup-Wald test
test <- supWald.RFF(
  Y = dat$Y,
  X = dat$X,
  Z = dat$Z,
  U = dat$U,
  B = 99,
  parallel = FALSE,
  n_cores = 8,
  bootstrap_seed = 123
)

test
```

When `parallel = FALSE`, `n_cores` is ignored.

For parallel computation on Windows or Linux:

```r
test <- supWald.RFF(
  Y = dat$Y,
  X = dat$X,
  Z = dat$Z,
  U = dat$U,
  B = 399,
  parallel = TRUE,
  n_cores = 8,
  bootstrap_seed = 123
)
```


The simulated example has nonzero regime-shift coefficients, so it is designed as an alternative rather than a null example.

## Parallel bootstrap

`supWald.RFF()` uses a multisession backend when parallel computation is requested, allowing the same interface on Windows and Linux. Use `n_cores` to choose the number of workers and `bootstrap_seed` for reproducible bootstrap calculations.
